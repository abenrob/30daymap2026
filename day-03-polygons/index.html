Paris, sorted

Pick an arrondissement. See what its buildings are used for, how big they are, then lift every one of them off the map and line them up from largest to smallest, at the same scale.

Buildings: IGN BD TOPO, batiment layer, buildings in service (Licence Ouverte 2.0). Arrondissements: IGN ADMIN EXPRESS. BD TOPO splits continuous street blocks into one building per plot, so a Haussmann block counts as several buildings. "Unspecified" is BD TOPO's own Indifférencié use. Made by Adam Roberts for the #30DayMapChallenge 2026, day 3: Polygons. Code and method.
