Day 16 · Collaborative map

Velographs: how far you can cycle in an hour, from anywhere on Earth

Velographs was a collaboration all the way around. I coded and built the posters, Ryan Morris automated it and built the site around it, so anyone could make a custom poster of how far they can cycle in an hour from any point on Earth. This one is San Francisco from Presidio Heights, in ten-minute bands.

My favourite thing about it is cartography by omission. Nothing on the poster draws a hill, a mountain or a coastline. They show up because roads cannot go there.

See it at velographs.com

Reach computed as line-based multigraph isolines with the Targomo API, on road data © OpenStreetMap contributors (ODbL). Automation and site: Ryan Morris. The code behind Velographs is not shared.
